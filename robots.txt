# ---------------------------------------------------------------------
# AI assistants and answer engines
#
# These are allowed deliberately. The goal is to be CITED when someone
# asks an assistant "who does flat pack kitchens in Rockhampton" — and a
# crawler that cannot read the page cannot cite it. Everything on this
# site is public marketing copy; there is nothing here we would withhold
# from a search engine but hand to a chatbot.
#
# Two corrections to the usual advice, because they change the decision:
#
#  1. Google-Extended does NOT control AI Overviews. AI Overviews is fed
#     by ordinary Googlebot. Google-Extended only governs Gemini app
#     grounding and Vertex AI training. Blocking it does not remove you
#     from AI Overviews — it only removes you from Gemini.
#
#  2. Blocking a training crawler is not the same as blocking a retrieval
#     one. GPTBot trains; OAI-SearchBot fetches pages to answer a live
#     question with a link back. Blocking OAI-SearchBot costs referrals;
#     blocking GPTBot does not.
#
# To opt out of model training while staying citable, disallow GPTBot,
# ClaudeBot, CCBot and Google-Extended, and keep OAI-SearchBot,
# ChatGPT-User, Claude-User/Claude-SearchBot and PerplexityBot allowed.
# ---------------------------------------------------------------------
