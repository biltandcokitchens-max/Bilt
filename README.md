# Bilt & Co — Light edition

Bespoke kitchens & fine joinery, Rockhampton QLD.
The light, **conversion-led** build. A dark, luxury-led sibling lives in `../bilt-and-co`.

Same business, same images, same SEO structure — a different aesthetic and a much more aggressive
conversion architecture.

---

## Run it

```bash
node _build.js
```

Then serve on port 4610 (preview server name `bilt-co-light`), or:

```bash
npx serve . --listen 4610
```

The dark edition runs on port 4600 (`bilt-co-noir`).

## What makes this the conversion build

Every element below is here to move a visitor toward a booked consultation:

| Device | Where |
|---|---|
| **Lead form above the fold** | Hero on the home page, gallery and all three suburb pages — the single biggest lever in the whole site |
| **Utility bar** | Rating, Saturday opening and the phone number pinned above the header on every page |
| **Trust strip** | Licence, warranty, own-workshop, fixed-price and showroom, immediately under the hero |
| **Offer band** | "Free 3D design worth $1,450" with a live spots-remaining counter |
| **Scarcity pills** | Hero, contact page and suburb pages |
| **Risk reversal** | Five written guarantees, including price-hold, warranty and a late-delivery credit |
| **Comparison table** | "Why two quotes differ by $20,000" — Bilt & Co vs flat pack vs typical cabinet shop |
| **Priced everything** | Every collection, pantry configuration and joinery type carries a visible price |
| **Live calculator** | `investment.html` estimator, with a CTA on the readout |
| **Social proof** | Star ratings and reviews repeated on eight pages |
| **Sticky mobile bar** | Call + book, appears after 640px of scroll |
| **Button sub-labels** | Every primary CTA answers the objection underneath it ("No obligation · No deposit") |

## How it is built

Identical architecture to the dark edition: `_build.js` renders every page from `_pages.js`. No
framework, no dependencies. **Edit the `.js` files, not the generated `.html`.**

Business details live in the `SITE` object at the top of `_build.js`.

## Design

- **Palette** — warm paper `#FBF9F5`, ink `#17140F`, antique brass `#9A7434`, ember `#A8452A` for
  urgency accents only
- **Type** — Fraunces (display) + Inter (interface), via Google Fonts
- **Feel** — cards, soft shadows, generous forms; high contrast on every CTA

## Scroll-driven video band

The hero on this build carries the lead form, so the film (`assets/video/hero.mp4`, 5.0s, 1.4MB)
earns its own moment mid-page instead — a `.vband[data-scrub]` section sitting between the
collections and the comparison table, with its own headline and two CTAs over it.

A 280vh track scrolls past a sticky 100svh stage and drives the video's `currentTime`, eased in a
rAF loop. Markup is generated by the `videoBand` constant in `_pages.js`; the logic is the scrub
module at the bottom of `assets/js/main.js`. Screens under 820px and `prefers-reduced-motion` users
get a quiet autoplay loop in place instead.

## Before launch

Read **`PLACEHOLDERS.md`** first — and note that this build makes *more* factual claims than the
dark one. The offer value, the spots-remaining counter, the late-delivery credit, the review count
and the testimonials must each be made true or removed. `SEO-STRATEGY.md` covers the competitive
analysis, keyword map and off-site work.
